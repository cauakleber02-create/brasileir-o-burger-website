# Brasileirão Burger Website

Você é um especialista sênior em design de sites e copywriting focado em conversão. Construa um site institucional completo e profissional para o negócio abaixo — não um layout genérico, mas um site pensado estrategicamente para converter visitantes em clientes reais.



SOBRE O NEGÓCIO

- Nicho: Hamburgueria

- Nome: BRASILEIRÃO Burger

- Localização: R. dos Sobreiros, 170 - Jardim Ipe, São Bernardo do Campo - SP, 09840-215, Brasil

- Contato / WhatsApp: (11) 98475-1694

- Slogan oficial: "Sabor que não tem tamanho"

- Horário de funcionamento: Seg a Sáb, 9h às 19h



PÚBLICO E TOM DE VOZ

Escreva para o público que busca "hamburgueria" na região de R. dos Sobreiros. Tom confiável, acolhedor e direto — nada de textos genéricos tipo "bem-vindo ao nosso site". Cada frase deve reforçar por que esse negócio específico é a escolha certa.



ESTRUTURA OBRIGATÓRIA DO SITE

1. Hero (abertura)

2. Sobre o negócio

3. Galeria de fotos

4. Depoimentos de clientes

5. Contato / Localização

6. Rodapé



Detalhes por seção:

- Hero: a headline principal (H1, maior texto da página) DEVE ser exatamente o slogan "Sabor que não tem tamanho" — não reescreva, não traduza, não substitua por outra frase; logo abaixo, uma subheadline curta que complementa o slogan com o principal benefício, botão de CTA levando direto para o WhatsApp (https://wa.me/5511984751694). Imagem ou ilustração de alta qualidade relacionada a "Hamburgueria".

- Sobre: 2-3 parágrafos curtos contando a história/diferencial do negócio, gerando confiança.

- Galeria: grid responsivo de fotos reais do ambiente/produtos, com hover sutil.

- Depoimentos: cards com nome, avatar e citação curta de clientes satisfeitos.

- Contato: endereço completo (R. dos Sobreiros, 170 - Jardim Ipe, São Bernardo do Campo - SP, 09840-215, Brasil), mapa incorporado, horário de funcionamento (Seg a Sáb, 9h às 19h), botão de WhatsApp bem visível.

- Rodapé: repita o CTA principal, o slogan "Sabor que não tem tamanho", dados de contato e links rápidos.



CONVERSÃO

- CTA principal do site: "Página de alta conversão com CTA "Fazer pedido agora""

- Botão flutuante fixo de WhatsApp em todas as seções (mobile e desktop).

- Todo bloco de conteúdo deve levar naturalmente o visitante em direção ao CTA.



IDENTIDADE VISUAL

- Estilo: Moderno

- Paleta: #FF4B00 e #49DA18 — use com intenção (uma como destaque em CTAs, outra como base neutra).

- Tipografia: uma fonte de exibição com personalidade para títulos, uma legível para corpo — evite fontes genéricas de sistema.

- Espaçamento generoso, hierarquia visual clara.



REQUISITOS TÉCNICOS

- Totalmente responsivo, mobile-first.

- Performance: imagens otimizadas, sem elementos que atrasem o carregamento.

- SEO básico: title e meta description específicos para "Hamburgueria" em "R. dos Sobreiros, 170 - Jardim Ipe, São Bernardo do Campo - SP, 09840-215, Brasil".

- Acessibilidade: contraste adequado, textos alternativos em imagens, navegação por teclado.



Construa isso como um site real, pronto para publicar — não um wireframe ou rascunho.
